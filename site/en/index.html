YouTube, Facebook and TikTok at once, from OBS.

Multistream is a free, open-source plugin for OBS Studio: one button streams to YouTube, Facebook, TikTok, any RTMP server and your Icecast radio at the same time, without copying stream keys or paying for Restream. For Windows, macOS and Linux.

Install Multistream View the source

Built for whoever runs the stream, not for whoever configures servers.

Accounts are connected once. After that, the operator only picks a title and destinations, and keeps an eye on everything staying red.

One window to go live everywhere

Title, description and destinations in one place. Recent broadcasts become templates: with {fecha} and {hora} (date and time), each week's title fills itself in.

  • Per-platform options on each row: YouTube visibility, set the Facebook video to private when it ends, a warning when TikTok will cut the title.
  • Estimated upload bandwidth before you go live.
  • If something is missing, the button says what.

One glance tells you what is live

Each destination has an indicator with its own shape and color: ready, sending, live, reconnecting or needs attention. Clicking any icon shows the full status, with a button to open each broadcast.

If one destination drops, the rest keep going

Each platform has its own connection. After a drop, Multistream retries on the same broadcast by itself; if it cannot, that destination is flagged and fixed on its own.

  • Retry: back to the same broadcast, with the same viewers.
  • New broadcast: creates another one on that destination only and ends the old one.

Your radio, without another app

Sends OBS audio to Icecast, AzuraCast or Liquidsoap, alone or together with the video. Replaces apps like BUTT and imports their settings.

  • MP3, AAC, Opus, Vorbis or lossless FLAC.
  • Any OBS audio track, for a separate mix.
  • Reconnects by itself; the password stays in the system keychain.

The details that matter once you are live.

Confirmation before ending
Ending asks for confirmation, and if the radio started with the video, it asks whether to stop it too.
Recovery after a crash
If OBS is force-closed, on the next start it tells you a broadcast was left open and ends it on each platform.
No stream keys in sight
Accounts are authorized in the browser and credentials stay in the macOS Keychain, Windows Credential Manager or the Linux secret service. That access is only used to create and manage your broadcasts; see the privacy policy.
One encoder
The same encoded video feeds every destination, so CPU load does not multiply.
Schedule ahead
Create the YouTube broadcast with a date and time, share the link, and on the day stream into that same broadcast.
Audible alerts
If a destination or the radio drops, or the audio goes silent for 20 seconds, Multistream warns you before the comments do.
Any RTMP server
Kick, Vimeo or your own server are added with their server and key, like any other destination.
Record at the same time
One checkbox records locally while you stream, so you keep the file without depending on the platforms.
Keyboard shortcuts
Start and end are assigned in the OBS hotkeys, like any other action.
Made for the OBS theme
Follows light and dark themes, works with the keyboard, and no state relies on color alone.

Install

  1. Download MultistreamFrom the latest release on GitHub. On Windows, get the …-windows-x64-instalador.exe installer; on macOS and Linux, the .zip for your system.
  2. Install it with OBS closedWindows: run the installer; it puts the plugin in the right folder. If Windows shows “Windows protected your PC”, choose “More info” and “Run anyway”. macOS: move obs-multistream.plugin to ~/Library/Application Support/obs-studio/plugins and clear the quarantine flag as the release notes explain. Linux: unzip it into ~/.config/obs-studio/plugins.
  3. Open OBS and connect your accountsClick any icon in the status bar and choose “Conectar” (Connect) for each platform.
  4. Press startPick a title and destinations, and go live.

Requirements

  • OBS Studio 33 or later (Help → About in OBS).
  • 64-bit Windows 10/11, macOS 13 or later, or 64-bit Linux with OBS outside Flatpak.
  • A Facebook Page, a YouTube channel enabled for live streaming and, for TikTok, an account with LIVE access through Streamlabs.
  • For radio: an Icecast, AzuraCast or Liquidsoap server.
  • The interface is in Spanish for now.

Google or Meta will not let your account connect? You can use your own Google and Meta apps (guide in Spanish).

Frequently asked questions

How do I stream to YouTube and Facebook at the same time with OBS?

OBS on its own streams to one destination. With Multistream you connect your accounts once, press the start button and pick YouTube, Facebook, TikTok or any RTMP server. The plugin creates each live broadcast with its title and description, sends the same signal to all of them and ends them when you stop.

Is it free? Does it add a watermark?

Yes, it is free and open source under the GPL-2.0 license. There is no watermark, no limit on destinations and no subscription.

Is it a Restream alternative?

Yes. Unlike Restream and other cloud services, the video goes straight from your computer to each platform, with no middleman and no paid plan. The trade-off is upload bandwidth: your connection sends one stream per destination, so three destinations at 6 Mbps need about 18 Mbps of upload.

Can I go live on TikTok from OBS?

Yes, if your TikTok account has LIVE access through Streamlabs. Multistream fetches the stream key for each broadcast, so you never copy it by hand.

How is it different from a multiple RTMP outputs plugin?

Those plugins send your stream to servers and keys you paste by hand. Multistream also creates and ends the broadcasts on each platform, warns you when one drops, retries on the same broadcast and can send the audio to an Icecast radio.

Can churches use it to stream services?

Yes, that is what it was built for. Templates put the date in each week's title, you can schedule the YouTube broadcast and share the link ahead of time, and the radio goes out together with the video.

Which systems does it run on?

64-bit Windows 10 and 11, macOS 13 or later and 64-bit Linux, with OBS Studio 33 or later. Windows has an installer. The interface is in Spanish for now.
